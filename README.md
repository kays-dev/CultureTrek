# CULTURETREK 🧭

Application iOS de randonnées culturelles gamifiées : on part sur le terrain, on résout des énigmes et des quiz, et on gagne des badges et des points d'expérience.

## 📓 CONTEXTE

Projet réalisé en équipe de 4 dans le cadre de l'Advanced Apple Foundation Program — formation Concepteur Développeur d'Applications chez SIMPLON.CO, de juillet à août 2026.

## 🎯 FONCTIONNALITÉS

- Découvrir : treks mis en avant et sections par région, avec filtres
- Liste et fiche détail des treks : distance, durée, dénivelé, accessibilité, bon à savoir, badges à débloquer
- Parcours sur carte, énigmes et quiz
- Fiche d'un trek terminé : photos, données de complétion et date
- Historique des treks sur une carte, avec filtres
- Profil : avatar, niveau et points d'expérience

## 🛠 TECHNOLOGIES

| Technologie | Usage |
|---|---|
| Swift / SwiftUI | Langage et interface |
| Observation | Gestion de l'état (stores partagés) |
| MapKit / CoreLocation | Cartes et localisation |
| PhotosUI | Ajout de photos |
| PopupView (Swift Package) | Fenêtres contextuelles |

## 🚀 INSTALLATION

1. Cloner le projet

   ```bash
   git clone https://github.com/kays-dev/CultureTrek.git
   ```

2. Ouvrir `CultureTrek.xcodeproj` dans Xcode (les dépendances Swift Package se téléchargent automatiquement)
3. Choisir un simulateur iOS ou un appareil
4. Build & Run (⌘R)
